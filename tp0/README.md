# Instrucciones para ejecutar

## Requisitos

Contar con una instalacion de Python 3.10 en adelante. No se requiere la instalacion de ninguna biblioteca mas alla del modulo *time* para corer las pruebas de tiempo.

## Comandos para correr el script

Suponiendo que se haya descomprimido la carpeta con el script, ejecutar:

```
cd tp0
python3 tp0_beloqui_112570.py
```
